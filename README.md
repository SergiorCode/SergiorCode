## 👋 My Journey

I build and ship product end to end — backend, infrastructure and the boring parts in between.

Most of my work lives in **[Pigui](https://pigui.ai)**, a B2B platform for brands and retail stores: catalogs, store and branch data, a lead engine, and billing. Alongside it I run **[CIV Bienestar](https://infonavit.center)**, a Flutter + FastAPI ecosystem deployed on Cloud Run.

Day to day that means Python and FastAPI, Flutter and Dart, Postgres and PostGIS, Google Cloud Run, and whatever else the problem needs — including a native macOS app in SwiftUI when I got tired of browser speed tests.
