  <summary><h2>👋 My Journey</h2></summary>

  I’m **Sergio Romero**, a **Chief Cloud Officer** based in Mexico. I came up through DevOps and SRE —
  Kubernetes, Terraform, CI/CD, multi-cloud across AWS, GCP and Azure — and I still do that work, only
  now I sit on the other side of the platform decisions too.

  Most of my day goes into **[Pigui](https://pigui.ai)**, a B2B platform for brands and retail stores:
  catalog, store and branch data, a lead engine and billing, running on FastAPI + PostgreSQL/PostGIS over
  Cloud Run. Alongside it I run **[CIV Bienestar](https://infonavit.center)**, a Flutter + FastAPI
  ecosystem behind an nginx router.

  Shipping product is what keeps the infrastructure honest: cold starts, region choices and query plans
  stop being diagrams and turn into latency somebody actually feels.
</details>
